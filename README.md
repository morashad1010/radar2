Build the best token launch radar. Reads the sealed snapshot, ranks pre-token protocols by implied value from TVL, 7d change, age, and chain factors. Writes board.json, data.js, dossier, and copies dashboard/ and screenshots/ to /output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input input/snapshot.json
```
